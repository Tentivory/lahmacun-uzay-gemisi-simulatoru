# 🚀 LAHMACUN UZAY GEMİSİ SİMÜLATÖRÜ

## ⚠️ KRİTİK UYARI
Bu proje, insanlık tarihinin en büyük sorunlarından birini çözmek için tasarlanmıştır: 
**"Acaba bu lahmacun uzaya çıkabilir mi?"**

Eğer bu soruyu daha önce sormadıysanız, tebrikler, artık soruyorsunuz. Hoş geldiniz.

## 🧪 Bilimsel Temel
Bu simülatör, NASA'nın, ESA'nın ve mahalle fırınının ortak çalışmasıdır (yalan).  
Algoritma tamamen rastgele sayılara, kuantum fiziğine (yalan) ve lahmacunun ruh haline dayanır.

### Kullanım
```bash
python simulator.py
```

Veya kendi lahmacununuzu test edin:
```python
from simulator import lahmacun_uzay_testi
lahmacun_uzay_testi(aci_seviyesi=8, peynir_miktari=7, maydanoz_orani=0.5)
```

## 📊 Sonuçlar Neyi İfade Eder?
- **40+** : Bu lahmacun kara deliği yutar.
- **20-40** : Uzay turizmine uygun, ama ekmek çabuk bayatlar.
- **0-20** : Lahmacun depresyona girer, dönüş bileti alın.
- **0 altı** : Fırından çıkmadan kaybolur. Fırıncıyı arayın.

## 🤔 Neden Bu Proje?
Çünkü dünya yeterince ciddi projelere sahip. Birisi de lahmacunun uzay kariyerini düşünmeliydi.
